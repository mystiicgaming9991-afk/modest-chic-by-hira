# Catalog image sources

Product visuals in this prototype are either supplied Modest Chic photography or generated illustrations. Generated illustrations communicate the intended product style and shade; they are not verified photographs of available inventory.

| Local file | Source / prompt summary |
| --- | --- |
| `modal-silk.webp` | Generated still life of softly draped modal silk in ivory, warm studio light. |
| `jersey-essentials.webp` | Generated still life of a soft olive jersey hijab with a matte finish. |
| `georgette-printed.webp` | Generated close-up of a botanical print georgette hijab in warm neutrals. |

| `hijab-magnet-duo.webp` | Generated still life of rose and ivory hijab magnets on folded fabric. |

Generated image prompts asked for square, photorealistic ecommerce still lifes in a cohesive warm ivory palette, with soft diffused light, no people, text, or logos. Images were converted to WebP for the site. The supplied Modest Chic collection images remain in the parent `public/images` directory and are unchanged.
